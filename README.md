## 它能压什么，压不了什么

功能列表不长，但都落在具体动作上：

- 拖一个文件进窗口，或者把整个文件夹丢进去，子文件夹一起处理

- 内置一批压缩预设，也能自己建配置，还能导出分享给同事

- 在 Finder、Safari 和预览的分享菜单里直接调用

- 支持带密码的 PDF

- 并排对比不同压缩设置的效果，压完先看再决定要不要替换原文件

- 查看 PDF 的标题、作者、关键词、图片数量和平均分辨率

- 把 PDF 里的图片整批导出

- 支持 PDF 1.0 到 1.7 以及 2.0

- 快捷指令、Automator 动作和命令行都能调

几个新版本加的东西挺实用。PDF/A-4 归档配置会在选定后自动关掉不兼容的压缩选项，适合要长期存档的文档。压缩配置里多了个「优化图像」开关，关掉它就只压其他内容，图片原样保留。侧边栏现在能按名称、原始大小、压缩比例、添加时间或状态排序，批量处理几十个文件时比之前好找。

压不了的部分同样明确：没有编辑、没有 OCR、没有电子签名、没有格式转换。它是一个压缩器，不是 PDF 编辑器。扫描件里的文字被压成图片之后，它不会帮你做文字识别。

## 哪些人该买，哪些人先别急

三类人买了大概率不后悔：

**经常被上传大小卡住的人。** 邮件附件超限、报名系统提示文件过大、签证材料传不上去，这类场景一两个月碰上一次，买断版一次性解决，不用反复找在线压缩网站，也不用把文件传到别人服务器上。

**要批量处理整个文件夹的人。** 一次几十份扫描合同、一整个作品集的图片型 PDF，拖进去走开就行。单文件压缩工具在这种量级上会让人崩溃。

**要固定输出规格的人。** 每次都按同一个画质档出图，配置存好，接上快捷指令或 Automator，或者直接在命令行里跑。有这块需求的话，20 美元的买断价很快就回本。

两类人可以先不买：

**需要改内容、做 OCR、加签名的。** 这类需求 PDF Squeezer 一个都解决不了，钱应该花在 PDF 编辑器上，两个工具不冲突但不能互相替代。

## 第三方评价里的优点和真实的坑

综合 Mac 应用测评站、MacUpdate 的功能记录和 Reddit r/macapps 的讨论，口碑集中在几件事上。

优点是控制力。预设档不够用可以自己调，调完还能存下来反复用；对比视图能直接看出这一档压掉了多少画质，不用靠猜。Reddit 上有人把 Clop 和它放在一起比较，结论是需要精细控制“画质让出多少”的时候选 PDF Squeezer。MacSources 的测评也提到，自定义配置和导出配置分享给同事是它区别于同类工具的地方。

缺点同样具体。

**激进档会把扫描件和照片压软。** 追求最小体积的那几档，肉眼能看出文字边缘发虚、图片细节丢失。测评站的建议是保留原文件，确认输出没问题再删。这个提醒不是客套话。

**它只做压缩一件事。** 你手上如果只有它，遇到要改一页文字或者合并两个 PDF，还是得另找工具。

**未来大版本可能要再付一次钱。** 前面说过，目前每个大版本内免费更新，但没有永久免费的书面承诺。

**大文件夹的导入体验是慢慢补上来的。** MacUpdate 的更新日志里，导入速度、进度显示、状态栏统计这几项反复出现改进记录，说明处理上千个 PDF 的文件夹时，早期版本并不算流畅。现在加了整体进度和单文件进度环，情况好一些。

Reddit r/macapps 的一个设计师帖子里，也有人提到 PDF Expert 自带的压缩对自己更合用。这说明它不是唯一解，只是在需要细致调节的场合更趁手。
